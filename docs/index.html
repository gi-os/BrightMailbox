Sign in to Mailbox

Make the code here, scan it on the phone. Nothing is typed on a 3.9-inch keyboard and nothing leaves this page.

1 — Make an app password

  1. Turn on 2-Step Verification at myaccount.google.com if it is not on already. Google only offers app passwords to accounts that have it.
  2. Go to myaccount.google.com/apppasswords, name it Mailbox, and copy the sixteen characters.

2 — Fill these in

Fill both fields to draw the code.

3 — Scan it

On the phone: ADD GMAIL → SCAN A CODE. Mailbox checks the password against Gmail before it saves it, so you will know at once if something was mistyped.

This code is a working password. Anyone who photographs it can read your mail. Do not screenshot it, do not put it in a chat, and close this tab when the phone has taken it.

You can revoke it whenever you like — same Google page, delete the entry named Mailbox, and the phone loses access immediately without affecting anything else.

This page runs entirely in your browser. There is no server, no analytics and no third-party script — the QR encoder below is part of the page, because asking you to trust someone else's script with a password would be the wrong shape. Source.
